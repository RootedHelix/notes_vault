# Summary
**`reflector`** is a utility used on **Arch Linux** to automatically **find, rank, and update the fastest package mirrors** for `pacman`.

Arch downloads packages from mirrors around the world. Some mirrors become:

- slow
    
- outdated (not synced with Arch repo)
    
- temporarily offline
    

`reflector` solves this by **testing mirrors and rewriting your mirrorlist with the best ones**.

---

## What it actually does

1. **Fetches the official Arch mirror list**
    
2. **Tests mirrors** based on criteria like:
    
    - speed
        
    - last sync time
        
    - country
        
3. **Sorts the mirrors**
    
4. **Writes a new `/etc/pacman.d/mirrorlist`**
    

This makes package downloads **much faster and more reliable**.
