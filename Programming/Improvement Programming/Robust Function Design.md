
### **Some Mnemonics To Help Remember**

- **"E.R.R.O.R."**
    
    - **E**xpect signals, partials, and system weirdness.
    - **R**ealistically check every return value.
    - **R**espond with clear error handling or logs.
    - **O**wn resource management and cleanup.
    - **R**eject assumptions about inputs/descriptors.
- **"Never Trust, Always Verify"** (every return value, every input)
    
- **"Write Once, Check Twice"** (every output—check its result and log if anything is wrong)
