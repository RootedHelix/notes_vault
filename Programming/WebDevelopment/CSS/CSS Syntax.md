
Three ways to integrate CSS with HTML.

1. Inline element: use the style="color: purple" attribute to write directly into the html and describe a specific html element (not recommended)
2. use the html <style> </style> element to embed css into the html (not recommended)
3. Link the html with an *External Style Sheet* with the < link > element in the head of the document(RECOMMENDED)
