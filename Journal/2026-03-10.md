## Embedded Project
Today I setup DMA to be able to be able to account for failures of the function: 

`hlx_ringbuf_write(&log_rb, (const uint8_t*)tmp, write_len);` 

by using peek and consume functions to essentially presave the state of the ringbuffer struct and then decide whether or not to update the state based upon success of the write function. 

Additionally I used [[__get_Primask()]] to be able to write a critical segment of code that is able to manage interrupt state properly within the log_write function so that it will avoid race conditions for the write function. The function was also made to be all or nothing in terms 
of either writing the full buffer or just chunks.
