## Embedded

Today I faced a Tool Desynchronization issue with `clangd` ([[Clangd Tool Desync]]) not parsing headers correctly and found the issue was through a premature include in one of my source files in the app source on the embedded repo. The fix was to just include the `main.h` instead of the direct HAL header. Then I configured my logger to communicate to `picomon` ([[WSL Packages]]) on my deployment computer to output the first logging message for the system. I had to ensure that the [[Baud Rate]] was properly set because if they are misaligned then `picomon` will output garbage. See [[WSL Embedded Logs]] for more information. I now have a fully asynchronous logger that is non-blocking and running through DMA. A huge win!
