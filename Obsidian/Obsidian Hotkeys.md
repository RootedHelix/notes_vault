#obsidian #obsidian_hotkeys
 
 
FULLSCREEN Application:     `Super + o`

Navigate back :                        `Cntrl + ALT + <-`

Open Settings :                         `Cntrl + ,`

Toggle Left Side Bar:                `ALT + 1 `

Open Command Palette:           `Cntrl + P`

Open Link (under cursor):       (Linux) `Alt + Enter` (Mac) `Option + Return`

Rename File Title:                      `F2`

Toggle Fold on Current line:      `Cntrl + Alt + F`
